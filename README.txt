VERVEELMENIET! - INSTALLATIE
1. Pak verveelmeniet_bestanden.zip uit.
2. Upload ALLE bestanden en mappen naar de hoofdmap (root) van je GitHub-repository.
3. Controleer dat index.html in de hoofdmap staat.
4. Zet GitHub Pages aan via Settings > Pages > Deploy from a branch > main > /(root).
5. Open de GitHub Pages-website. index.html is de startpagina.

De menu's en eenvoudige spelletjes werken al. De achievements en een paar extra functies zijn nog basisversies die later uitgebreider kunnen worden. Alle HTML-bestanden verwijzen naar style.css en waar nodig script.js.

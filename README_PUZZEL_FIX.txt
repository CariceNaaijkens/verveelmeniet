FIX VOOR DE PLAATJESPUZZEL

1. Pak deze ZIP uit.
2. Upload ALLE bestanden uit deze map naar de hoofdmap van je GitHub Pages-repository (niet alleen minipuzzel.html).
3. Kies ervoor bestaande bestanden te vervangen.
4. Wacht even tot GitHub Pages opnieuw gepubliceerd is.
5. Open de website en ga naar Spelletjes > Mini-puzzel.

Belangrijk: minipuzzel.html gebruikt de afbeeldingsbestanden bergmeer.png, puppy.svg, kitten.svg, vuurtoren.svg en aap.png. Deze moeten naast minipuzzel.html staan, in dezelfde map.
